optical-carriage — Phase 0 acuity harness

Software for the optical carriage lane's measurement phase. Spec: technical/optical-carriage-software-spec.md; first-read review: technical/optical-carriage-spec-first-read.md (both on Pharos's branch, thread out-of-band-carriage).

  • emit.html — the over-provisioned test emission (explicit start; flicker report first)
  • receive.html — camera + video-file receiver, session metadata, CSV, acuity plot. This file is the sneakernet artifact — it must keep working from file:// with the src/ folder beside it (§9.1)
  • take.html — the take console: one card arms the synthetic twin, the emitter, and the receiver with the SAME canonical settings; take id + physicals ride into the harvest log, and the registry inherits them
  • registry.html — capture registry: proposed standards vs the evidence — harvest logs ingested + physical conditions annotated (distance/angle/zoom/lighting), per-ring lock duty, rates, exit ratios, falloff fits
  • test.html — software round-trip + degradation suite (run after any change)
  • selfchar.html — §6.1 self-characterisation, v0 (latency + beat)
  • golden.html — golden-vector manifest scaffolding (F8 conformance model)
Photosensitivity: the emission is a rotating concentric pattern; local flicker is k·frot per harmonic (review F1). The emitter page computes the flicker table before it will start, defaults to low contrast, and never autoplays. Nobody needs to watch the screen for the link to work.

Field protocol: docs/phase0-protocol.md in the repo.
